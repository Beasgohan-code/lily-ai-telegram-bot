Repository integration findings

User-provided repositories inspected via GitHub CLI:
- https://github.com/abhinai2244/Auto-Rename
- https://github.com/abhinai2244/FileToLink
- https://github.com/abhinai2244/AniwatchTvdl
- https://github.com/abhinai2244/ENCODING-BOT
- https://github.com/abhinai2244/LLM-Powered-Intelligent-Query-Retrieval-System
- https://github.com/Codeflix-Bots/Post-Search-Bot

Licenses and reuse constraints:
- Auto-Rename includes Apache License 2.0.
- FileToLink has no LICENSE file in the shallow clone; do not copy its code.
- AniwatchTvdl includes GPLv3.
- ENCODING-BOT includes AGPLv3.
- LLM-Powered-Intelligent-Query-Retrieval-System includes GPLv3.
- Post-Search-Bot’s license was not yet confirmed in the inspected output.

Useful design patterns identified:
- Auto-Rename: filename placeholders, caption templates, thumbnail/progress UX.
- AniwatchTvdl: richer AniList GraphQL fields, cleaned title fallback search, genre/studio/cover metadata, queued download/upload progress.
- ENCODING-BOT: FFmpeg CRF/preset/codec/resolution/audio settings, stream probing, throttled progress updates, metadata/subtitle options. Its host-bypass/direct-link utility should not be copied into Lily.
- FileToLink: separate upload/link service architecture, Redis/Mongo deployment concepts; no code reuse because no license was found.
- LLM retrieval system: document extraction and query/retrieval concepts, but its LangChain/Google stack is heavier than Lily’s core.
- Post-Search-Bot: indexed-channel search, result cards, force-subscription flow, timed cleanup, and separate user-session architecture. Lily should implement a local indexed-post search and explicit access checks rather than importing a userbot session or unlicensed code.

Integration decision:
- Use high-level patterns and independently implemented code. Do not copy GPL/AGPL/unlicensed source into Lily without deliberate license handling.
- Extend Lily with Rose-style moderation modules, filters, locks, warnings, notes, local indexed-post search, and richer anime metadata.
